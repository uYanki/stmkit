# 串口下载

![img](.assets/README/819239-20210629150636821-1205985874.png)

V1.5及其以下版本

芯片的下载程序都是需要断电上电, 为防止板载的串口芯片使用TX引脚给模块供电,使用了反向二极管.

这也导致了芯片那端的RX引脚处于悬空状态.

![img](.assets/README/819239-20210809095558816-1919979503.png)

需要PA8接4.7K电阻到3.3V, 方可使用串口下载

![img](.assets/README/819239-20210809095411091-1750053278.png)

选择串口 -- 点击下载

![img](.assets/README/819239-20210809100245825-608793819.png)

给芯片断电上电,即可实现下载

![img](.assets/README/819239-20210809100619919-1609720857.png)
