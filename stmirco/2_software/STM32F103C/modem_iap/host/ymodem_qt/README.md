```

  Download image to the internal Flash ----------------- 1

  Upload image from the internal Flash ----------------- 2

  Execute the loaded application ----------------------- 3

  Enable the write protection -------------------------- 4

==========================================================

CCCStart program execution......
```

在切到 SerialPortYmodem，连接串口，选择文件，下载程序。
